# NitroPerks

A nostalgic project from the early days of my development journey.

**Unlock All Nitro Features** is a BetterDiscord plugin created to simulate the availability of Discord Nitro features locally in the client interface. It was built as an experimental project while learning about Discord client modifications and plugin development.

> ⚠️ This repository is preserved for archival and educational purposes only.

---

## 📜 Overview

This plugin modifies the Discord client UI to unlock and preview certain Nitro-exclusive interface features locally.

It was originally created around **5 years ago** as one of my early projects exploring client-side modifications and plugin architecture within the BetterDiscord ecosystem.

The goal was simple:
- Experiment with Discord's client structure
- Learn plugin development
- Explore UI feature unlocking

This project is now kept here purely for **nostalgia and historical reference**.

---

## ⚠️ Important Notice

This project:

Use at your own risk.

---

## 📦 Features (Historical)

The plugin originally attempted to simulate access to features such as:

- Nitro emoji usage
- Client-side Nitro UI features
- Various UI unlock experiments

Note that many of these were **client-side only** and did **not bypass server-side restrictions**.
